# سامانه طراحی و وب‌سایت سه‌بعدی ردیابی خودرو، GPS و مدیریت ناوگان

این مخزن شامل **وب‌سایت اصلی سه‌بعدی فارسی (RTL)**، **دیزاین سیستم کامل (`DESIGN.md` + `tokens/`)** و **آزمایشگاه کالبدشکافی هندسه مادر و تایپوگرافی «پیدا»** است که تماماً از فایل‌های هسته برند (`COLORS.md`, `logo.svg`, `typography.svg`, `3d_front.pdf`, `gradiant.pdf`, `peyda/*.ttf`) استخراج و ساخته شده‌اند.

## ساختار مخزن

- **`DESIGN.md`** — سند مرجع و جامع دیزاین سیستم (کالبدشکافی هندسی لوگو و لوگوتایپ، هندسه رنگ و گرادیان ۱۴۰.۲۴ درجه، قوانین کنتراست WCAG، تایپوگرافی ۹ وزنه پیدا، مواد سه‌بعدی، ۵ لایه فضایی `Z-0..Z-4`، ۶ پترن حرکتی و کاتالوگ کامپوننت‌ها).
- **`tokens/`** — توکن‌های رسمی دیزاین سیستم:
  - `tokens/design-tokens.json` — استاندارد W3C DTCG
  - `tokens/tokens.css` — متغیرهای CSS Custom Properties و قطبیت شب/روز
  - `tokens/tokens.js` — خروجی جاوااسکریپت / Three.js و پیش‌تنظیم Tailwind CSS
- **`public/brand-clean/`** — نسخه‌های برداری تمیز و بدون میکروذرات لوگو (`logo-clean.svg`) و لوگوتایپ (`typography-clean.svg`).
- **`src/components/website/`** — ۷ پرده وب‌سایت اصلی سه‌بعدی ردیابی خودرو و مدیریت ناوگان (شامل صحنه سه‌بعدی قهرمان، رادار زنده کریدورهای ایران، کالبد انفجاری ۴ لایه سخت‌افزار GPS در Three.js، بخش روز شنی هوشمند، تایم‌لاین کلوتوئیدی محموله، ماشین‌حساب بازگشت سرمایه و تعرفه‌ها).
- **`src/components/design-system/`** — پورتال زنده و تعاملی دیزاین سیستم (مرورگر بصری توکن‌ها، ۹ وزن فونت پیدا، کامپوننت‌های عملیاتی ناوگان و کپی مستقیم کد توکن‌ها).
- **`src/components/`** — آزمایشگاه کالبدشکافی هندسی مرحله ۱ و ۲ و فیلم تعاملی مونتاژ لوگو و سیگنال مسیر.

## اجرا و ساخت پروژه

```bash
npm install
npm run dev     # اجرای سرور توسعه روی پورت 5173
npm run build   # ساخت نسخه تولید (Production)
```

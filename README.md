# سامانه هوشمند ردیابی خودرو، GPS و مدیریت سه‌بعدی ناوگان

وب‌سایت محصول و سامانه طراحی فارسی (RTL) مدیریت هوشمند ناوگان، مبتنی بر `React + Vite + Three.js` و خانواده تایپوگرافی بهینه‌سازی‌شده `Peyda`.

## معماری مسیرها (جداسازی محصول از ابزارهای مهندسی)

- **`/` (`index.html` → `src/main.jsx`)**: وب‌سایت نهایی مشتری‌محور مدیریت ناوگان (بدون لینک‌ها یا کدهای ابزار داخلی).
- **`/design/` (`design/index.html` → `src/design-main.jsx`)**: پورتال داخلی دیزاین سیستم، مستندات زنده کامپوننت‌های `src/ds/` و آزمایشگاه هندسه برند (`/design/?view=lab`).

## دستورات توسعه و گیت‌های کنترل کیفیت

```bash
# اجرای سرور توسعه
npm run dev

# تولید خودکار tokens/tokens.css و tokens/tokens.js از tokens/design-tokens.json
npm run tokens:build

# بازرسی خودکار استایل‌ها و توکن‌ها (stylelint + اسکن بدون هگز/rgba/cubic-bezier خام)
npm run lint:tokens

# آزمون خودکار کنتراست WCAG 2.1 AA روی تمام زوج‌های رنگی
npm run test:contrast

# بیلد کامل تولید (شامل ساخت توکن + بازرسی توکن + آزمون کنتراست + بیلد چندصفحه‌ای Vite)
npm run build
```

## مستندات مرجع

- [`DESIGN.md`](./DESIGN.md): مرجع عملیاتی دیزاین سیستم، توکن‌های معنایی، تایپوگرافی، کامپوننت‌ها و قواعد Do/Don't.
- [`docs/brand-derivation.md`](./docs/brand-derivation.md): گزارش مهندسی استخراج پارامترها از فایل‌های مرجع و تفکیک اندازه‌گیری‌ها از تصمیم‌های طراحی.
- `reports/`: گزارش‌ها و اسکرین‌شات‌های مقایسه‌ای قبل و بعد (رسپانسیو، لایت‌هاوس و کنتراست).
